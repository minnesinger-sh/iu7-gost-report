# Свод правил: как пользоваться

Правила разложены по уровням. Каждый уровень ниже уточняет или отменяет
уровень выше только в своей области.

## Уровни и приоритет

Чем выше номер в списке, тем выше приоритет:

1. Указание пользователя в текущей задаче, задание работы, замечание
   преподавателя к этой работе.
2. Правила работы — `local/<курс>-<NN>.md` (не входят в систему контроля версий).
3. Правила курса — `courses/<курс>.md`.
4. Правила типа документа — `documents/<тип>.md`.
5. Общие правила — `common.md`, `research.md`, `build.md`.
6. Опыт прошлых работ — `experience.md`. Это подсказки: при расхождении
   с любым уровнем выше не применяются.

Норма ГОСТ (в `common.md` помечена ссылкой на пункт стандарта) отменяется
только явным требованием задания, преподавателя, курса или пользователя;
такое расхождение записывается как отступление от ГОСТ.

## Что читать

| Задача | Файлы |
| --- | --- |
| Любой отчёт | `common.md`, `build.md` |
| Лабораторная работа | + `documents/lab-report.md` |
| Лабораторная по «Анализу алгоритмов» | + `courses/algorithm-analysis.md`, `local/aa-<NN>.md` |
| Тесты, измерения, графики | + `research.md`, `experience.md` |
| Курсовая работа, НИР | + `documents/<тип>.md` и файл курса, когда они появятся |
| Выбор или выпуск версии преамбулы | `preamble.md` |
| Проверка нормы стандарта | `gost/INDEX.md` и текст стандарта |

Если для типа документа или курса файла ещё нет, его создают при первой
работе этого типа по тому же образцу.

## Как записывать правило

Одно правило — один пункт. После текста в скобках указывается источник:

- `(ГОСТ 7.32-2017, п. 6.4)` — норма, пункт проверен по тексту стандарта;
- `(задание)` или `(замечание преподавателя, 12.11.2026)`;
- `(решение пользователя, 16.11.2026)`.

Перед записью найти тему правила во всех уровнях:

- такое правило уже есть — не дублировать, при необходимости уточнить его;
- противоречие на том же уровне — заменить старый пункт, а не дописывать новый;
- отличие от уровня выше — записать на своём уровне явной отменой:
  «Вместо правила "<кратко>" из `common.md`: …».

Нижний уровень содержит только отличия и дополнения, а не пересказ верхних.
Отменённые формулировки удаляются; история хранится в системе контроля версий.

## Куда записывать

| Правило относится к | Файл |
| --- | --- |
| оформлению любого отчёта | `common.md` (тесты и измерения — `research.md`, сборка — `build.md`) |
| одному типу документа | `documents/<тип>.md` |
| одному курсу | `courses/<курс>.md` |
| одной работе | `local/<курс>-<NN>.md` |
| полезному опыту без жёсткого требования | `experience.md` |
