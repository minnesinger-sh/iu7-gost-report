# Курс «Анализ алгоритмов» (ИУ7, 5 семестр)

Восемь лабораторных работ, оформляемых как научно-исследовательские.
Тип документа — `documents/lab-report.md`. Правила отдельных работ —
`local/aa-<NN>.md`.

## Отличия от общих правил

- Реферат в отчёты не включается: после титульного листа — содержание.
  Отступление от ГОСТ 7.32-2017. (решение пользователя, 04.11.2026)
- Программы пишутся на Го (Go). Питон (Python) не используется, даже если
  он упомянут в варианте. (общее задание курса)
- Распределение задач по частям, состав введения и заключения берутся
  из задания конкретной работы; при расхождении с `documents/lab-report.md`
  действует задание.

## Примечания преподавателя к оформлению

Из примечаний к заданию ЛР № 1; сверять с заданием каждой работы.

- Цель и задачи — во введении, без отдельного подраздела.
- Заключение: «Цель работы достигнута: …», затем «Все задачи решены:»
  и перечень по задачам введения.
- Тесты — таблицей: «№», «Описание теста», «Входные данные»,
  «Ожидаемый результат» (при необходимости «Полученный результат»);
  под таблицей — «Все тесты пройдены успешно». Листинг тестов — в приложении А.
- В списке источников — хотя бы один рецензируемый источник (учебник, книга).

## Модель вычислений для трудоёмкости

Текст пользователя (ноябрь 2026); приводится в конструкторской части
перед расчётом трудоёмкости.

- Стоимость 1: `+`, `-`, `=`, `+=`, `-=`, `==`, `!=`, `<`, `>`, `<=`, `>=`,
  `[]`, `++`, `--`, `&&`, `>>`, `<<`, `||`, `&`, `|`.
- Стоимость 2: `*`, `/`, `%`, `*=`, `/=`, `%=`.
- Условный оператор: f = f_условия + min(f1, f2) в лучшем случае,
  max(f1, f2) в худшем.
- Цикл: f = f_иниц + f_сравн + M · (f_тело + f_инкр + f_сравн).

Уточнения конкретной работы — в её файле `local/aa-<NN>.md`.

  образования „Московский государственный технический университет
  имени Н.Э. Баумана (национальный исследовательский университет)“
  (МГТУ им. Н.Э. Баумана)»; «бюджетное» — ошибка. (замечание бота
  кафедры ИУ7 к ЛР № 1 и № 2, 17.11.2026)
- MR проверяет бот кафедры (@machineSpirit, «ДухМашины») по списку типовых
  ошибок; его замечания исправляются как замечания преподавателя.
- Ссылки на рисунки, таблицы и листинги в исходниках — через обычный
  пробел между словом и номером (`рисунке \ref{…}`), не через `~`: бот,
  по-видимому, не считает `~` разделителем. После сборки проверить по
  извлечённому тексту, что слово и номер не разорваны переносом строки;
  при разрыве — `\mbox{рисунке \ref{…}}`. (решение пользователя
  по замечанию бота «нет разделителя между названием типа иллюстрирующего
  элемента и его номером», 17.11.2026)
- В `main.tex` после преамбулы: заголовок «СПИСОК ИСПОЛЬЗОВАННЫХ
  ИСТОЧНИКОВ», `\appendixpart` (нумерация «А.1»), `\reportpart` (часть
  с новой страницы), `\codelisting`; `\srcdir` и `\testdir` — каталоги
  кода и тестов для листингов.
- Код в листингах — пакетом `fvextra` (`\codelisting`), а не `listings`:
  под XeLaTeX `listings` нарушает порядок кириллицы в строках кода.

## Рисунки

- Схемы и графики — отдельными файлами `report/img/<имя>.tikz` (только
  `tikzpicture`); `make figures` собирает их в векторные
  `report/img/<имя>.pdf` с той же преамбулой (`figure.tex`,
  `figstyles.tex`). Отчёт вставляет PDF через `\includegraphics{<имя>}`.
  PDF рисунков хранятся в работе; PNG не делаются. (решение пользователя, 12.11.2026)
- Стили схем (`subroutine`, `note`, `connector`, `\blocknote`) —
  в `figstyles.tex`; обозначения, общие для текста и рисунков, —
  в `00-macros.tex`.

## Сборка

- Из корня работы: `make test` (`go vet`, `go test`), `make report`
  (`latexmk -xelatex`, итог `output/pdf/report.pdf`).
- Пользователь собирает на macOS в MacTeX. Шрифты для сборки вне macOS —
  в `iu7-gost-report/.fonts/`; они не публикуются (лицензия).
- Замеры — только на ноутбуке пользователя; в отчёте — его характеристики.

## Копия для сдачи

Требование кафедры к репозиторию работы: `code/`, `test/`, `report/`
(каталоги с tex-файлами, картинками и пр.), `report/report.pdf` не больше
15 МБ.

- `make submit [SUBMIT=<путь>]` собирает копию (по умолчанию
  `../submit/lab-NN`, удобнее — клон учебного репозитория): `code/` — код
  без тестов, `test/` — `*_test.go`, `report/tex/` — tex-файлы
  и `00-preamble.tex`, `report/img/` — PDF рисунков и герб, `report/data/` —
  замеры, `report/report.pdf`. В корень — `Makefile` из `tools/submit/`
  (`make test`, `make report`, `make clean`), в `report/tex/` — `.latexmkrc`
  (XeLaTeX, сборка в `report/build/`), в `.gitignore` дописываются
  недостающие строки.
- В папке сдачи заменяются только `code/`, `test/`, `report/`; `.git`,
  `README.md`, `.gitignore` не трогаются.
- Исходники рисунков (`*.tikz`, `figure.tex`, `figstyles.tex`) в копию
  не входят. (решение пользователя, 12.11.2026)
- Учебный репозиторий: отдельный проект на каждую работу, задачи — в Redmine.
  Работа сдаётся веткой от `main` и Merge Request с названием, равным номеру
  задачи без `#` (`1276`); правки по замечаниям — новыми коммитами в ту же
  ветку. (замечание преподавателя Строганова Д. В., 16.11.2026)
