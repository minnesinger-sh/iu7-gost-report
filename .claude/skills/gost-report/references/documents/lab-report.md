# Лабораторная работа

Уточнения `common.md` для отчёта о лабораторной работе, оформляемого
как научно-исследовательская работа. Курс и задание могут менять состав.

## Состав и порядок

Титульный лист, (реферат — если курс его не исключает), содержание,
введение, четыре нумерованные части, заключение, список использованных
источников, приложения.

Нумерованные части: «Аналитическая часть», «Конструкторская часть»,
«Технологическая часть», «Исследовательская часть». Если задание называет
части иначе, используются его названия.

## Что в какой части

Если задание не распределяет задачи по частям иначе:

- **Аналитическая:** определения, постановка задачи; короткие сведения
  об ограничениях входных данных — в постановке, без отдельного подраздела.
- **Конструкторская:** подраздел «Требования к программе», схемы
  алгоритмов, теоретические оценки времени и памяти, функциональное
  тестирование (классы эквивалентности).
- **Технологическая:** средства реализации и сведения о вычислительной
  системе (в одном подразделе), реализация, практическая оценка памяти
  реализации, результаты тестирования.
- **Исследовательская:** методика измерений, результаты, сравнение
  и выводы (`research.md`).

## Введение и заключение

- Во введении: предмет работы с определениями используемых терминов,
  одна цель, задачи маркированным перечнем.
- Заключение повторяет перечень задач тем же порядком, с результатом
  по каждой; развёрнутые сравнения из исследовательской части не дублируются.

## Приложения

- Приложение А — исходный код; листинги нумеруются «Листинг А.1»,
  в тексте частей на них есть ссылки.
